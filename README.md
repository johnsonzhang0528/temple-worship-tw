# 🏮 全台廟宇一鍵參拜 — 走春拜拜不出門

> 過年走春拜拜行程，不用東奔西走人擠人！在家就能參拜全台知名廟宇，體驗滿滿年味互動。

## ✨ 功能特色

- 🏯 收錄全台 20+ 知名廟宇
- 🙏 一鍵參拜：上香、擲筊、抽籤完整體驗
- 🧧 新春求籤詩 & 解籤
- 🎆 滿滿年味動畫與音效
- 📱 支援手機與桌面瀏覽器
- 🗺️ 走春路線模擬，集章收集

## 🚀 快速開始

```bash
# 直接開啟
open index.html

# 或用任意靜態伺服器
python3 -m http.server 8080
npx serve .
```

瀏覽器開啟 `http://localhost:8080` 即可體驗。

## 🎊 體驗流程

1. 選擇廟宇（依地區分類）
2. 進入廟宇場景
3. 上香參拜（三拜動畫）
4. 擲筊問卜
5. 抽籤求詩
6. 集章紀念
